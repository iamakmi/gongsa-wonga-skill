### 1-④ 공종별 찾기 → 합치기 (일위대가 작업의 기본 방식)

일위대가는 **전체를 한 번에 찾지 않는다. 공종별로 나눠 찾고, 공종마다 검산한 뒤, 마지막에 합친다.** 공종마다 맞는 자료(①②③)와 품셈 책이 다르기 때문이다. 한꺼번에 찾으면 엉뚱한 책의 항목이 섞이고, 어느 공종에서 금액이 틀렸는지 찾기 어렵다.

| 단계 | 할 일 | 결과물 |
|---|---|---|
| 1. 공종 나누기 | 설계내역·견적·공사내용의 품목을 공종별로 묶고 6자리 코드를 붙인다(`010101 철거`, `010102 목공`…). 발주처 코드가 있으면 그대로 쓴다. 폐기물·운반은 경비 공종으로 따로 뺀다 | 공종 목록표(코드·공종명·품목 수·설계 소계) |
| 2. 공종별 찾기 | 공종 하나씩 차례로: 자료 순서(①발주기관 → ②실내건축 → ③표준품셈)대로 찾되 ①②와 노임·자재가는 §1-⓪ md 합본의 해당 구간(건축/기계/전기/토목)에서 grep 으로 찾고, ③이면 3번 스킬의 책 구분과 공종별 체크표로 찾는다. 품목마다 호표 구성(품·수량·노임 직종·공구손료·REMARK)과 출처 코드를 옮긴다. 못 찾은 품목은 "미확인"으로 남긴다 | 공종별 중간 파일 `work/gongjong/{코드}_{공종명}.json` |
| 3. 공종별 검산 | 그 공종의 재료·노무·경비 소계를 설계내역 공종 소계와 대조하고, 차액과 원인을 적는다(§8 금액 차이 표 기준) | 공종별 대조표(공종·설계 소계·산출 소계·차액·원인) |
| 4. 합치기 | 공종 코드 순서로 중간 파일을 모아 데이터 모듈 하나로 합친다. 호표 번호는 전체에서 1번부터 이어 매긴다. **같은 출처 코드 + 같은 규격**이 여러 공종에 나오면 호표 하나로 합치고 두 공종이 같은 호표를 참조하게 한다. 그다음 `SEC_HEAD_ROW`·`SEC_TOT_ROW`·`HOPYO_ROW` 등 딕셔너리를 만들어 2번 스킬 사양으로 8시트를 생성한다(§2-3) | 원가계산서 xlsx |

**사용 방식**

| 요청 | 처리 |
|---|---|
| "원가계산서 만들어줘" | 1~5단계 전부. 2·3단계는 공종마다 끝날 때 공종별 대조표에 한 줄씩 채우고, 5단계 전에 대조표 전체를 사용자에게 보여 준다 |
| "목공 일위대가 찾아줘" (공종 하나만) | 1~3단계만 그 공종에 대해 하고, 공종별 대조표와 호표 구성을 표로 보여 준다. 중간 파일을 남겨 두어 나중에 그대로 합칠 수 있게 한다 |
| "도장 공종 추가해줘" / "철거만 다시 찾아줘" | 그 공종만 2~3단계를 다시 하고 중간 파일을 바꾼 뒤, 4~5단계로 다시 합친다. 다른 공종의 중간 파일은 건드리지 않는다 |
| "철거 공종 빼줘" | 그 공종의 중간 파일을 목록에서 빼고 4~5단계로 다시 합친다(행 삭제가 아니라 재생성, §2) |

## 2. 절대 규칙 — 수식 연결 보존 (모든 편집에 우선)

연결 체인 : `수량(건축)1 → 일위대가(건축) → 일위대가목록(건축) → 공종별내역서 → 공종별집계표 → 원가계산서 → 갑지` (+ `단가대비표 → 일위대가`). 연결이 끊기면 그 파일을 버리고 다시 만든다.

1. `delete_rows`/`insert_rows` 금지(병합 범위와 수식 참조가 따라가지 않는다). 항목을 뺄 때는 값·테두리만 비우고 `hidden=True` 한다. 그 행을 참조하던 반대편 행도 같이 비운다(한쪽만 비우면 `0`이나 `#REF!` 가 된다).
2. 어쩔 수 없이 행을 옮길 때는 값과 스타일을 직접 옮기고, SUM 범위와 행 번호가 박힌 수식, 그 행을 가리키는 다른 시트의 수식까지 전부 다시 쓴다.
3. **시트 참조 행번호를 하드코딩하지 않는다.** 생성할 때 딕셔너리로 넣는다(`AG_TOT`, `AG_WASTE_ROW`, `SEC_HEAD_ROW[code]`, `SEC_TOT_ROW[code]`, `HOPYO_TOTROW[no]`, `HOPYO_ROW[no]`). 공종 추가·삭제는 데이터 모듈 한 곳만 고쳐 다시 생성하고, 참고사항과 개정 이력도 함께 정리한다(공종 하나를 빼 달라는 요청은 반드시 온다).
4. openpyxl : `cell(row,col,value=None)` 로는 값이 안 지워지므로 `ws['E104']=None` 으로 쓴다. 병합셀에 쓰기 전에 `unmerge_cells` 한다. 병합은 값을 쓴 뒤에 한다. 병합을 두 번 등록하면 테두리가 사라진다. 시트명을 바꾸면 수식 참조와 print_area 문자열도 치환한다.
5. 저장한 직후 비운 행 번호로 모든 수식을 검사하고 `#REF!` 를 검색한다. 1건이라도 나오면 다시 만든다.
6. 사용자가 고쳐서 돌려준 파일은 받는 즉시 모든 시트를 셀 단위로 비교한다(구글시트를 거치면 print_area·title_rows·row_breaks·바닥글이 사라진다). `1` vs `1.0`, `=SUM(F197:F197)`→`=SUM(F197)` 같은 차이는 무시하고, 참조가 바뀐 셀만 의도한 수정인지 확인한다.

```bash
libreoffice --headless --convert-to xlsx --outdir /tmp/rc "<파일>.xlsx"     # 재계산
libreoffice --headless --convert-to pdf:calc_pdf_Export --outdir /tmp/chk "<파일>.xlsx"
pdftoppm -jpeg -r 80 -f 2 -l 2 /tmp/chk/*.pdf /tmp/chk/pg   # 육안 확인 후 rm -rf /tmp/chk
```

## 3. 파일명 · 버전 · 산출물 · 업체정보

- 파일명 `{공사명}_{문서종류}_v{N}.xlsx`, 괄호 금지. **산출물은 xlsx 만**(시방서를 같이 낼 때는 docx). PDF 는 사용자가 요청할 때만 만든다. 임시로 렌더한 PDF 는 확인 후 지운다(두 판본이 돌면 PDF 만 옛 버전으로 남는다). 그래서 인쇄 설정(용지·방향·인쇄영역·반복 제목행·페이지나눔·바닥글)을 xlsx 안에 반드시 넣는다.
- 전달은 SendUserFile 로 하고, 연결 폴더가 있으면 그 폴더에도 저장한다.
- **전달할 때마다 버전 +1**(서식만 고쳤어도). 전달하지 않는 중간본은 버전 없이 덮어쓴다. 폴더에서 가장 큰 vN 을 찾아 +1 하고, 한 번 쓴 번호는 다시 쓰지 않으며, 이전 버전을 지우지 않는다. xlsx 와 시방서 docx 는 같은 버전 번호로 맞춘다. 구글시트 버전기록으로 대신하지 않는다.

```python
import re, glob, os
def next_ver(outdir, base):
    vs=[int(m.group(1)) for f in glob.glob(os.path.join(outdir, f'{base}_v*.xlsx'))
        if (m:=re.search(r'_v(\d+)\.xlsx$', os.path.basename(f)))]
    return max(vs)+1 if vs else 1
```

- 참고사항 시트 `Ⅴ. 개정 이력` 에 버전마다 한 줄씩 적는다(Ver | 작성일 | 변경내용 | 작성자 | 비고). 비고에는 금액 변동 여부를 반드시 적는다(`금액 변동 없음` / `투찰율 90% 적용, 결정금액 △1,000,000`).
- **업체정보** (아래는 가정 예시 — 실제 사용 시 자기 회사 정보로 바꾼다) 가나다건설 주식회사 000-00-00000 / 대표 홍길동 / ○○도 ○○시 ○○구 ○○로 123, 1층 / TEL 02-000-0000 / FAX 0000-000-0000 / 담당 010-0000-0000 / 업태 건설업·종목 실내건축공사 / example@example.com. 갑지에 로고는 넣지 않는다. 직인은 사용자가 이미지로 찍는다(임의로 그리지 않는다). 견적번호는 `YYYYMMDD-1001` 부터 +1.

### 5-1. 한글 금액 수식 (갑지·요약 금액)

`NUMBERSTRING` 은 구글시트·LibreOffice 에서 빈칸으로 나오므로 쓰지 않는다. 갑지·참고사항·요약 금액은 전부 원가계산서를 참조하는 수식으로 쓴다(파이썬 계산값을 박아 넣으면 금액이 바뀌어도 갑지만 옛 금액으로 남는다).

```python
UNITS={1:'',2:'천',3:'백',4:'십',5:'',6:'천',7:'백',8:'십',9:''}
def kor(ref):
    S=f'TEXT({ref},"000000000")'
    def part(k):
        u=UNITS[k]; d=f'MID({S},{k},1)'
        dg=f'MID("영일이삼사오육칠팔구",VALUE({d})+1,1)'
        return f'IF({d}="0","",IF({d}="1","{u}",{dg}&"{u}"))' if u else f'IF({d}="0","",{dg})'
    g2='&'.join(part(k) for k in (2,3,4,5)); g3='&'.join(part(k) for k in (6,7,8,9))
    return (f'IF({ref}=0,"영",{part(1)}&IF(MID({S},1,1)="0","","억")&{g2}'
            f'&IF(VALUE(MID({S},2,4))=0,"","만")&{g3})')
def amt(ref, tail=''):
    return f'=":   一金"&{kor(ref)}&"원정   ( ₩"&TEXT({ref},"#,##0")&".- )"{tail}'
```

조각을 `&` 없이 이으면 `#VALUE!` 가 나고, `&"원정"` 을 빠뜨리는 실수가 잦다. 합계금액은 `amt("'원가계산서'!D35")`(필요하면 `&"  ( VAT 포함 )"`).

### 5-① 기본 — 투찰율 100% 설계금액 파일 (요구가 없으면 이것 하나만)

100% 와 투찰율을 한 파일에 `IF` 로 같이 넣지 않는다(어느 쪽이 계약금액인지 모호해지고, 마스터 셀을 건드리면 금액이 통째로 바뀐다). 산식은 §5-0 그대로 쓰고 G·H 보조계산과 갑지 J2 는 만들지 않는다. 비고 `F29 설계요율 8 % ( 법정 상한 )`, `F30 설계요율 15 % ( 법정 상한 ) — 천원미만 절사분 조정`, `F31 투찰율 100 % — 설계금액 ( 천원미만 절사 )`.

### 5-② 요구할 때만 — 투찰율 판본 (별도 파일)

"투찰율 90%로 줘"처럼 명시할 때만 100% 파일을 복사해 새 버전으로 만든다. 갑지 J2(투찰율 마스터, GOLD)·J4(`='원가계산서'!D34+'원가계산서'!D35`)와 원가계산서 G·H 보조계산을 추가한다.

```python
k['J2']=0.9
w2['H5']='=ROUNDDOWN(D28*8%,0)'
w2['H6']='=ROUNDDOWN((D10+D27+H5)*15%,0)'
w2['H7']='=ROUNDDOWN((D28+H5+H6)/1000,0)*1000'
w2['H8']="=ROUNDDOWN(H7*'갑지'!$J$2/1000,0)*1000-D28"   # D31 을 참조하지 않는다(순환)
w2['D29']='=ROUND($H$8*H5/(H5+H6),0)'
w2['D30']='=D31-D28-D29'
w2['D31']="=ROUNDDOWN(H7*'갑지'!$J$2/1000,0)*1000"
```

**직접공사비와 법정경비는 절대 줄이지 않는다.** 산재·고용·석면·임금채권·산안비가 함께 깎이면 지적 대상이고, 산안비는 산안법 제72조상 감액할 수 없다. 투찰 차액은 일반관리비·이윤에서만 흡수한다. D7·D10·D27 은 투찰율과 상관없이 같아야 한다(달라졌으면 단순 곱셈을 한 것이다). 구성비·비고는 실제 요율을 따라가게 한다 : `E29="[ 재료비 + 노무비 + 경비 ] × "&TEXT(D29/D28*100,"0.###")&" %"`, `E31="설계 공급가액 × 투찰율 "&TEXT('갑지'!$J$2,"0.###%")&" ,  천원미만 절사"`, `F29=IF('갑지'!$J$2=1,"법정 상한 8%","투찰율 "&TEXT('갑지'!$J$2,"0.###%")&" 역산  (상한 8%)")`. 갑지 `A22` 에 `=IF(J2=1,"","   ※ 본 견적은 투찰율 "&TEXT(J2,"0.###%")&" 를 적용한 금액이며, 직접공사비 및 법정경비는 감액하지 않고 일반관리비·이윤에서 역산 조정하였음.")`. 파일명과 개정이력 비고에 변동액을 적고, 두 파일을 함께 넘길 때는 어느 쪽이 계약 기준인지 밝힌다. 연동 순서 : J2 → D31 → D29·D30 → D32 → D33 → D35 → 갑지 한글금액.

### 5-③ 관급자재 · 산안비

관급자재는 내역서 재료비 단가를 지우고(수량은 유지), 규격에 `[ 관급자재 ]` 를 적고, 원가계산서 34행에 합계를 넣는다. 결정금액 = 도급액(VAT 포함) + 관급자재비(VAT 별도). 설치 주체가 불분명하면 반드시 묻는다. 산안비 대상액 = 재료비 + 직접노무비 + **도급자가 설치하는** 관급자재(납품업체가 설치하면 제외) → `=ROUND((D7+D8+도급자설치관급)*3.11%,0)`.

### 5-④ 제비율 (10억 미만·6개월 이하·5억 미만 건축 기준)

간접노무 직접노무비×17.5% / 기타경비 (재료+노무)×5% / 일반관리비 순공사원가×8% / 이윤 (노무+경비+일반관리비)×15% / 산재 노무비×3.56% / 고용 1.01% / 건강 직접노무비×3.595% / 연금 4.75% / 노인장기요양 건강보험료×13.14% / 퇴직공제 직접노무비×2.3% / 산안비 3.11% / 환경보전 (재료+직노+직경)×0.5%(주택 외 건축) / 석면 0.006% / 임금채권 0.09% / 하도급보증 0.081% / 건설기계보증 0.07%.

**요율은 고정값이 아니다.** 공사 규모·기간·계약방법에 따라 구간이 갈리고 고시가 매년 바뀐다. 착수할 때 규모 구간을 확인하고 최신 고시(요율·고시번호)를 웹으로 검증한다. 제외 요건 : 건강·연금·노인장기요양은 공사기간 30일 미만, 퇴직공제는 추정금액 1억원 미만이면 제외. 산안비는 총공사금액 2천만원 이상이면 반드시 계상(미계상 시 과태료, 법 제72조·제175조).

### 5-⑤ 구성비(E) 표기

산식만 쓴다(문장·사유 금지). 비목은 `[ ]` 로 감싸고 곱셈은 `×`, 항 사이 ` + `, 요율 끝의 0 은 뗀다(`3.56 %`). 비워 두는 행 : 직접재료비·간접재료비·작업설부산물·직접노무비·직접경비·건설폐기물처리비·모든 [소계]·공급가액·도급액·관급자재비·결정금액. 계상하지 않는 비목도 산식은 남기고, 0원인 이유는 비고(F)에 적는다(`제외 — 공사기간 30일 미만`, `관급자재 없음`). 비고에는 적용조건·제외사유만 쓴다(`모든공사`, `1개월이상공사`, `1억원이상공사`, `최저가대상공사`, `천원미만절사`, `★법정 필수 · 감액 금지`).

## 6. 일위대가 · 공종 배분 원칙

1. **호표 합계가 기준이다.** 목표 단가를 따로 박아 두고 구성내역을 별도로 쓰면 목록·내역서·집계표가 몇 원씩 어긋난다. 폐기물·운반은 경비로 다시 분류한다(총액은 그대로).
2. **자재 단가는 설계내역 값을 그대로 쓰고 추정하지 않는다.** 원본 호표의 재료 할증(1.05·1.20 등)은 적용하지 않는다. 설계단가가 이미 실제 투입량 기준이어서, 할증을 곱하면 총액이 5~20% 부풀려진다. 이 사실을 REMARK 에 한 줄 남긴다. (표준품셈의 "재료 할증 확인" 규칙보다 이 규칙이 우선이다.)
3. **합성 호표**(예: 목재 칸막이 철거 = 철거-21×2면 + 철거-17)는 원본을 각각 계산해 더하지 않는다. 구성품목을 한 호표로 합친 뒤 계를 내고, 합계에서 **원 미만은 버린다(`int`)**. 각각 반올림해 더하면 1~2원이 어긋난다. 비고에 원본 코드를 모두 적고 REMARK 1항에 합성한 사실과 준용 근거를 쓴다. 합성 호표 계가 견적 단가와 거의 같으면 그 견적서는 이미 일위대가로 짜인 것이다(㉮를 골라도 총액이 크게 변하지 않는다).
4. 4×8 판재는 장 단위로 환산한다(2.9768㎡/장). 할증을 넣지 않았다는 사실을 비고에 적는다.
5. 준공청소는 관공서 공사에서 계상하는 항목이다(가설-36 등). "품셈 외"로 빼지 않는다.

### 6-1. 발주기관 일위대가 PDF 변환 · 조달청 표준공사코드

**PDF 변환** : 목록 부분을 `pdfplumber` 좌표로 파싱해 숨김 참조 시트로 넣는다(외부 링크는 끊긴다). 열은 `x0` 가 아니라 **가운데 좌표** `(x0+x1)/2` 로 판정한다. 4자리 호표는 `호표`와 숫자가 다른 줄로 갈리므로 위아래 조각행을 모두 흡수한다. 호표 번호 `1..N` 이 이어지는지 확인하고, 끊긴 곳은 주황색 + `원문 확인 필요` 로 표시한다. 코드 열(A)에 `GA-0001` 을 매기고 원문 번호는 따로 보존한다. 단위가 다르면 환산값을 곱한다(장 단위 `*2.9768`).

**PCCES** : `https://npccs.g2b.go.kr:8785` 에서 로그인 없이 조회하고 엑셀로 내려받는다. 경로 `명칭조회 > 세부공종` → 공사구분 → 검색어를 **직접 타이핑한 뒤 Enter**(프로그램으로 넣으면 필터가 안 걸린다). 코드는 12자리(건축 `A`, 토목 `C`). 필수인 경우는 조달청 발주·C3R 검증 제출·표준시장단가 적용 공사뿐이다. 일치도(일치·유사·준용)와 적용 근거(발주기관 호표)를 함께 적는다. 적는 곳 : 일위대가목록 K·L열 / 단가대비표 비고 `▣ 조달청 표준공사코드 : …` / 호표 제목줄 끝.

### 6-2. 공사리스트 관리대장

[리스트] 22열에 매번 등록한다(K열 실적신고 업종/공사규모/적용기술/공법, L열 비고 = 버전·일위대가 출처·호표·제비율·제외비목·관급자재·정정사항). 버전마다 I·L 을 고친다. 대장 위치를 모르거나 접근이 안 되면 추측하지 말고 묻는다.

| 수식 | 고아 참조·`#REF!` 0건 / 비운 행의 반대편도 비웠는가 |

## 8. 자주 막히는 지점

| 증상 | 원인 | 처치 |
|---|---|---|
| 결정금액 전액 0 | 집계표 단가·금액 열이 뒤바뀜 | 단가 열에 내역서 소계, 금액은 `=단가*수량` |

| 수천원 차이 | 동명이품 수량 참조 행을 잘못 연결 | 품명+규격 **완전일치** 매핑(`startswith` 금지) |
| 수백원 이하 차이 | 품×노임 재계산 절사 | 정상, 보고만 |

| 품셈에서 설비·전기 항목이 안 나옴 | 건축 책만 찾음 | 3번 스킬 책 구분 |

| 서식·인쇄 문제(`###`, 빈 페이지, 뭉개짐) | | 2번 스킬의 표 참고 |

## 9. 작업 순서

1. §0 질문(일위대가 기준·공사기간·관급 설치주체·투찰율·PCCES·규모 구간). 견적서가 있으면 대조표와 차액을 먼저 계산해 함께 묻는다.
2. 버전 확인 : 요율·고시(§5-④), 품셈·노임·재료 기준일(3번 스킬). §1-⓪ md 폴더가 공사 시점의 반기 자료인지 확인하고, 합본 구간 줄번호를 `grep -n '^# '` 로 다시 확인한다. 파싱했으면 합계를 원본과 1원까지 맞춰 본다.
3. 공종 나누기(§1-④ 1단계 — 발주처 코드 우선, 폐기물·운반은 경비).
4. 공종별 찾기·검산(§1-④ 2~3단계, 공종 하나씩). 공종별 대조표를 사용자에게 보여 준다.
5. 합치기(§1-④ 4단계) → 호표 작성 원칙(§6) 적용 → 일위대가목록.
6. 수량산출 → 단가대비표 → 필요하면 PCCES 병기(§6-1).
7. 모든 시트를 수식으로 연결하고 공종별 소계 합·결정금액을 원본과 대조(§1-④ 5단계, §8 표).
8. 투찰율 판본일 때만 J2 를 바꿔 재계산해 갑지까지 따라오는지 확인(§5-②).
9. 2번 스킬 서식 확정 → 칸 넘침 정리 → 그룹화 → 인쇄 설정.
10. §7 검수 + 2번 스킬 검수 → 임시 PDF 육안 확인 → 임시 PDF 삭제.
11. 버전 +1 로 저장 → 개정 이력 추가 → 관리대장 등록 → xlsx 만 전달.
