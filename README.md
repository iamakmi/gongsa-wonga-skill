## 설치

```

~/.claude/skills/wonga-2-chulryeok-yangsik/SKILL.md

```

`skills/` 안의 세 폴더를 위 위치(`~/.claude/skills/`)에 복사하면 됩니다.

## 쓰기 전에 꼭 바꿀 것 (가정 예시로 들어 있음)

공개용이라 회사·공사 정보는 모두 **가정 예시**입니다. 자기 것으로 바꿔 쓰세요.

- 업체정보 : `가나다건설 주식회사`, 대표 `홍길동`, 사업자번호 `000-00-00000`, 주소·전화·메일 (1번 §3, 2번 §1-1 갑지)
- 기준 파일 이름 : `가나초등학교_과학실_환경개선공사_공사원가계산서_v1` (2번 §1)
- 자료 폴더 경로 : `<자료폴더>`, `<품셈폴더>` (1번 §1-⓪, 3번 §0)
- 발주기관 : `○○교육청` — 호표 번호·합본 줄번호는 예시이므로 자기 발주처 자료에서 다시 찾으세요
- 금액 사례(견적 대조, 투찰율 차액 등)는 설명용 가정 숫자입니다
